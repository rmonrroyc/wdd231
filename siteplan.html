Individual Project Site Plan

Project: One Page Web Studio

Site Name

One Page Web Studio

This name was selected because it clearly communicates the main focus of the website: designing and building one-page websites. The name is simple, descriptive, and easy to remember, which supports branding and recognition.

Optional domain availability: onepagewebstudio.com

Site Purpose

The purpose of this website is to present a web design studio that specializes in creating one-page websites for small businesses, entrepreneurs, and independent professionals. The site will provide information about one-page websites, describe available services, showcase website features or packages, and allow visitors to contact the studio through an online form.

Scenarios

  • What is a one-page website and is it a good option for my small business?
  • What services or website packages are available and how can I request one?

Color Scheme

  • Primary Color (#123f56): Used for headings, navigation elements, and primary branding areas.
  • Secondary Color (#ec9018): Used for accents, buttons, highlights, and calls to action.
  • Background Color (#f5f7f8): Used as the main page background to maintain readability and contrast.

Typography

  • Arial / Helvetica / sans-serif: Used for all body text and general content to ensure readability and accessibility.
  • Font-weight variations: Used for headings and emphasis to create visual hierarchy.

Wireframes

Mobile View

This wireframe represents the mobile-first layout of the home page. Content is stacked vertically to support scrolling and usability on small screens.

The layout includes a header with navigation, a hero section, service information, a call-to-action area, and footer content.

Desktop / Tablet View

This wireframe illustrates the layout for larger screens, where content is displayed using wider sections and multi-column designs.

It includes horizontal navigation, a prominent hero section, structured content areas, service grids, and a footer for navigation and additional information.
